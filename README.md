## Sobre
Sou **Marcos**, também conhecido como **SayNoob_TYT**, criador da **TYT Studios**. Construo interfaces web, dashboards e experiências de estudo para Android, com atenção a navegação clara, personalização e uso no celular.

Este perfil reúne projetos autorais, protótipos e experimentos. Quando uma demonstração usar dados fictícios ou estiver em estágio inicial, isso fica indicado no próprio projeto — sem promessas de produto pronto ou resultados que não existem.

## Foco atual · Material You
Estou desenvolvendo o [**Material You Starter Kit**](https://github.com/in3zalo-gk/material-you-starter-kit): uma base open source inspirada em Material 3 e Material 3 Expressive, com tokens CSS, demo web e exemplo Android em Kotlin/Jetpack Compose com Dynamic Color no Android 12+.

É um projeto independente, em evolução e sem vínculo com a Google. [Ver código e próximos passos →](https://github.com/in3zalo-gk/material-you-starter-kit)

## Foco atual: Material You Starter Kit

Estou desenvolvendo o **[Material You Starter Kit](https://github.com/in3zalo-gk/material-you-starter-kit)**: um kit open source de interfaces inspiradas em Material 3 e Material 3 Expressive, com tokens CSS e uma demo web, além de um exemplo Android em Kotlin e Jetpack Compose com Dynamic Color no Android 12+.

Projeto em estágio inicial, independente e sem vínculo com a Google. [Explorar o projeto e contribuir](https://github.com/in3zalo-gk/material-you-starter-kit).
